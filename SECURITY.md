# Security Policy

## Reporting

Report security concerns privately to the repository owner. Do not post
credentials, private project names, local paths, or deployment details in
public issues or pull requests.

## Scope

This is a generated public catalog. Its reviewed source controls which public
project names, links, and broad categories may appear. Do not use the catalog
to publish private portfolio structure, operational documentation, or local
environment details. Use an issue with a public repository URL for ordinary
catalog corrections, without including sensitive disclosure details.
